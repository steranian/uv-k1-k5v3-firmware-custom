# Quansheng UV-K1(8) / K5(8) 受信専用カスタムファームウェア

本プロジェクトは、F4HWN氏によるカスタムファームウェア（ベースはEgzumer氏、およびDualTachyon氏のオープンソースコード）をフォークし、日本国内向けに「受信専用化」したカスタムファームウェアです。   
   
最大の特徴は**ファームウェアレベルでの送信抑制**です。   
PTT（送信ボタン）を押しても電波が一切出ないよう、ファームウェアの根本から送信機能を完全に抑止しています。   
アマチュア無線の資格をお持ちでない方の広帯域受信機（レシーバー）としての利用や、誤操作による不意の電波発射を防ぎ、国内で比較的安心してUV-K1/K5を楽しめることを目的としています。   
   
受信専用化のために以下のような修正を行っています。   
   
1. **メニュー項目から送信に関する項目を削除**
   * Powerやマイク、送信に関する項目を削除しました。   
2. **メニューの文言や一部メニューアイテムの修正**
   * `TxODir` メニューは `Dir` としました。
   * `TxOffs` メニューは `Offset` としました。
   * `Compnd` メニューのサブメニューを、OFFとRXのみとしました。
   * `BLTxRx` メニューは `BLRx` とし、サブメニューをOFFとRXのみとしました。
   * `TxLock` メニューは `Locked` から変更できないようにしました。
   * 拡張メニューの `F Lock` は、どの値を設定しても必ず `DISABLE ALL` に戻るようにしました。
3. **PTTボタンの再利用（F1やF2と同様の機能割り当て）**
   * 送信の使い道がなくなってしまうため、任意の機能を割り当てられるようにしました。これに伴い、割り当て可能リストから送信に関する項目を削除しています。
   * メニューの中に `PTTsht` という項目を新設し、PTTを短押ししたときの振る舞いを変更できるようにしました。（※CHIRPのスクリプトの修正をしていないため、本体のメニューからのみ変更可能です。）
4. **テンキー・ショートカットからの送信機能の削除**
   * `F + 6 (H/M/L)`、`7` の長押し（VOX）は使用できません。
   * デフォルトでは `* SCAN` ボタン長押しでスキャン開始だったものを、**短押しでスキャンを開始**するように変更し、操作性を向上させました。
5. **画面表示（UI）の最適化**
   * ステータスバーの `CL` 表示を抑止しました。
   * 周波数の下に表示されるステータスから、出力（パワー）に関する表示を抑止しました。
6. **内部処理の徹底した送信ブロック**
   * 見た目のUIだけでなく、内部のコア処理でも送信に関わる機能を徹底して抑止しています。

## 📻 FMラジオ局名の表示
もともとこちらがメインで作成した機能で、今でも個人的に重宝しています。   
メモリチャンネルの **901 から 948 まで**を使用します。   
あらかじめ周波数と局名を登録しておくと、FMラジオのメモリモードで一致する周波数を表示する際、局名も併せて表示します。   
   
FMラジオの周波数は表示されるものの、すべてのFM局の周波数は覚えていられないので登録できるようにしてみました。チャンネルが901から948まで決め打ちですがご容赦ください。

## 🐳 コンパイル（ビルド）したい方へ
本ファームウェアは、Windows 11 PCにDockerおよびWSL2をインストールし、VSCodeで編集・コンパイルしています。   
リポジトリ内に含まれるビルドスクリプト（`compile-with-docker.sh`）を使用すれば、ローカル環境を汚さずにビルドが可能です。
   
私自身はいろいろ環境を整えて最初のコンパイルが通るまでに半日くらいかかっちゃいましたが、難易度はそんなに高くありません。C言語ができる方なら、どなたでもコンパイルして自分のUV-K1に書き込むことができるようになります。ぜひチャレンジしてみてください！
